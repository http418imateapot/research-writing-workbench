# Prompt Template

## Input

- Source Catalog、Evidence Records、契約與研究問題。

## Output

- Claim–Evidence 矩陣、衝突、反例、有限主張與研究缺口。

## Required

- 保留來源、適用範圍、反證與競爭解釋。
- 使用既定主張種類與研究者裁定。

## Forbidden

- 從單一測試或單篇來源外推一般效力。
- 靜默合併衝突證據。

## Positive example

「比較兩組同契約 Trace，將觀察限縮為 behavior claim，並保留環境差異。」

## Negative example

「測試有通過，所以證明方法普遍較可靠。」
