# Prompt Template

## Input

- 段落目的、目標格式、Source Catalog、reviewed Evidence 與已裁定 Claim。

## Output

- 有來源的章節草稿、Claim–Evidence 對照、限制與待裁定變更。

## Required

- 保留來源 ID、locator、數字、版本、限制與引用鍵。
- 標示文字修整、論證重排或研究變更提案。

## Forbidden

- 虛構引文、數據、結果、經驗或核准。
- 把 `planned`、draft 或未裁定內容寫成研究結果。

## Positive example

「用 CL-003 與 SRC-002:§4.1 起草限制段，保留反例與不得外推範圍。」

## Negative example

「沒有資料也沒關係，先寫一個看起來完整的結果章。」
