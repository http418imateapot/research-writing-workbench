# Prompt Template

## Input

- 題目、問題背景、研究對象與版本。
- 可用時間、環境、材料與不可變更限制。

## Output

- 有界研究問題、驗證契約、情境矩陣、證據計畫與里程碑。

## Required

- 區分 `planned`、已取得產物與實際執行。
- 明列反駁條件、排除範圍與研究者決策點。

## Forbidden

- 虛構來源、執行、結果、數字或核准。
- 把建議方法寫成已完成研究。

## Positive example

「為非同步命令完成語意規劃研究問題與四個可反駁情境；全部先標為 `planned`。」

## Negative example

「替我直接寫出實驗成功且效能提升的結論。」
