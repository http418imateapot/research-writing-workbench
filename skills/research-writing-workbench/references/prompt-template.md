# Prompt Template

## Input

- 系統、版本、工程異常、研究問題與排除範圍。
- 程式、測試、Trace、Log、Diff、論文或執行紀錄位置。

## Output

- CTCC 狀態、適用 Skill 路由、證據缺口、反例與有限主張。

## Required

- 保留既有 ID、成熟度、主張種類與研究者裁定。
- 將規劃、實際執行、AI 判讀與人工決策分開。

## Forbidden

- 虛構來源、執行、Trace、數字、結果、經驗或核准。
- 將工程實作直接擴張成研究有效性。

## Positive example

「路由這組程式與 Trace，先補 validation contract，再做 counterexample review。」

## Negative example

「只看 README 就宣稱系統可靠且研究方法有效。」
