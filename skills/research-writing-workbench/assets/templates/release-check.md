# Release Check

| 檢查項目 | 判定 | 位置或依據 | 必要動作 |
|---|---|---|---|
| 契約與版本可定位 | stop | [未取得產物] | 補 contract ID |
| scenario 與 execution 可重建 | stop | [尚未重現] | 補執行紀錄 |
| 原始產物與整理結果分開 | stop | [未取得產物] | 建立 Trace Index |
| 反例與競爭解釋已處理 | revise | [待研究者裁定] | 完成反例審查 |
| 主張種類與證據相符 | stop | [待研究者裁定] | 完成主張紀錄 |
| AI、隱私、授權與政策已核對 | stop | [待研究者裁定] | 由研究者確認 |

判定限 `pass`、`revise`、`stop`。
