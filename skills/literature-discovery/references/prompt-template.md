# Prompt Template

## Input

- 研究問題、主題詞、範圍、時間與可用資料庫。

## Output

- 檢索策略、查詢紀錄、Source Catalog、Corpus Snapshot 與缺口。

## Required

- 保存查詢式、日期、納入／排除理由及驗證狀態。
- 為每筆來源提供穩定 ID 與可核對位置。

## Forbidden

- 虛構書目、DOI、頁碼或全文內容。
- 將未驗證 metadata 寫成確認事實。

## Positive example

「搜尋 2021–2026 年 event replay 研究，保留完整檢索式並逐筆標記 DOI 驗證狀態。」

## Negative example

「憑印象列二十篇看起來合理的引用。」
