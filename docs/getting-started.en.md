# Getting started

Open the repository in Codex and invoke `$research-writing-workbench` with the system and version, reproducible event, available code/tests/traces/logs/diffs, execution environment, research question, and protected content.

Build the toolkit and install the required self-contained directory from `dist/agents-skills/`. Start with the [Engineering Question Brief](../skills/research-writing-workbench/assets/templates/engineering-question-brief.md) and [Validation Contract](../skills/research-writing-workbench/assets/templates/validation-contract.md). Keep missing artifacts as `[未取得產物]` and unreproduced work as `[尚未重現]`.

If repository skills are unavailable, use the [Traditional Chinese master prompt](../prompts/master-prompt.zh-TW.md). Do not upload tokens, private source code, customer data, or identifiable full logs.
